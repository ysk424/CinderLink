# Provenance and clean implementation record

CinderLink is an independently authored implementation based on public interface documentation and ordinary Unreal Engine plugin APIs.

## Sources used for behavior

- Public OpenAI Codex App Server documentation and schemas generated by the user's installed official Codex CLI.
- Public Unreal Engine documentation and installed public C++ header declarations needed to compile a plugin against Unreal Engine 5.8.
- Public Cesium for Unreal header declarations used only to verify that CinderLink's generic Unreal reflection subset covers common Arrietty-UE scene settings; CinderLink does not include or link Cesium code.
- Windows API documentation for child-process, pipe, environment-block, and Job-object behavior.

## Excluded material

No source code, binary code, assets, user-interface layouts, text, names, comments, tests, or generated files from NeoStack or any other proprietary Unreal AI extension are included or adapted. CinderLink does not require those products to build or run.

Contributors must not submit code copied or translated from proprietary extensions. Describe behavior using public documentation or independently observed requirements, then implement it independently. Every contribution must comply with [CONTRIBUTING.md](CONTRIBUTING.md).

## Repository contents

The repository contains only CinderLink-authored source, configuration, documentation, and build/audit scripts. It does not contain Unreal Engine code or content, Codex binaries, OpenAI credentials, or compiled plugin binaries.
